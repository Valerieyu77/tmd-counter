# 🤬 他妈的记录器

统计你在电脑上（微信、Claude、ChatGPT……）打出去多少个“他妈的 / 妈的 / 他妈”。

## 安装（发给朋友时把这段一起发）

1. 到 [Releases](https://github.com/Valerieyu77/tmd-counter/releases/latest) 下载 `他妈的记录器.zip`，解压，把 app 拖进“应用程序”文件夹。
2. 第一次打开：**右键 → 打开 → 打开**。（没有苹果开发者签名，直接双击会被拦。）
   还是打不开的话，在终端运行：
   `xattr -dr com.apple.quarantine /Applications/他妈的记录器.app`
3. 系统会提示授予“辅助功能”权限：去 系统设置 → 隐私与安全性 → 辅助功能，把它打开。
4. 菜单栏出现 `🤬 0` 就说明在工作了。

## 用法

点菜单栏的 🤬：
- 看今天的次数、各个词的次数、聊天 / AI 的占比、最近几条
- **打开统计页面**：按小时、按 app、按聊天窗口统计，还有语录搜索
- **复制今日战报**：复制一段文字，直接粘贴到微信群里
- **检测微信**：微信好像没记到时，用它排查

## 怎么算一次

在输入框按回车，并且输入框随后被清空（也就是消息真的发出去了），才算一次。
只是按回车让输入法上屏、或者换行，都不会计数。

## 微信为什么会闪一下

新版微信（4.x）不让别的程序读输入框。所以在微信里按回车时，记录器会先自动 ⌘A 全选、⌘C 复制，
读出要发的内容，再放行回车让消息发出去，最后把剪贴板恢复原样。整个过程约 0.15 秒，
你可能会看到输入框闪一下被选中。用拼音打字还没上屏时按的回车不会被拦。
如果你用了剪贴板管理工具（Paste、Raycast 等），它可能会记下这次复制。

## 隐私

- 只保存含脏字的那一句，其他聊天内容读完就丢，不会保存。
- 所有数据都在本机：`~/Library/Application Support/TMDCounter/`，不联网。
- 菜单里可以关掉“保存原句”，这样只记次数，不记内容。

## 局限

- 只能统计电脑上打的字，手机微信统计不到。
- 终端里的 Claude Code 不算（终端没有能清空的输入框）。
- “我妈的手机”这类不算；“你妈的”算。偶尔会有误判。
